NEXUS ORBIT — VERSÃO ESTÁTICA

Para abrir a página, extraia esta pasta e clique duas vezes no arquivo index.html.
Não é necessário instalar Node.js, executar comandos ou usar hospedagem local.

Estrutura:
- index.html: página principal
- css/style.css: estilos visuais
- js/script.js: interações
- images/: imagens utilizadas pela página

Observação: Nexus Orbit é uma demonstração institucional. Substitua os textos e as informações demonstrativas por dados reais e verificáveis antes de qualquer publicação.
